# 益账通 · 全渠道权益积分与储值资产管理平台

一个轻量、纯本地存储的多渠道个人权益、积分、有价卡券及储值卡管理平台。

## 主要功能

- **多渠道资产统一纳管**：整合银行、电商零售、生活平台与航司酒店渠道的积分、储值卡、有价卡券及次数权益，自动换算人民币预估价值。
- **App 内权益路径记录与检索**：记录每个权益在对应 App 内的具体访问与核销路径，支持关键词实时搜索与一键复制。
- **临期卡券与积分消费提醒**：支持自定义预警窗口（15 / 30 / 60 / 90 天），按剩余天数排序展示，支持暂缓提醒与一键跳转核销。
- **单笔与综合消长明细**：记录入账获取（`+`）、核销消费（`-`）、过期作废（`-`）及盘点调整；支持自动核算消费优惠（原价 - 实付），并支持导出 CSV。
- **动态趋势与优惠汇总分析**：交互式 SVG 趋势图展示资产估值、累计节省金额及每日消长柱状流向；汇总各渠道、类型及月度省钱排行。
- **本地存储与数据备份**：全部数据保存在浏览器 `localStorage`，支持全量 JSON 备份导出与导入恢复。

## 本地运行

```bash
npm install
npm run dev
```

默认访问地址：`http://localhost:3000`

## 构建生产版本

```bash
npm run build
```
